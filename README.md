<summary><strong>◎ Pipeline CRM — resumen de oportunidades comerciales</strong></summary>

Calcula el importe total de cada etapa y el valor ponderado de las
oportunidades abiertas. Los importes se guardan en céntimos.

```js
const oportunidades = [
  { empresa: "Demo Norte", etapa: "contacto", importe: 180000, probabilidad: 0.2 },
  { empresa: "Demo Sur", etapa: "propuesta", importe: 320000, probabilidad: 0.6 },
  { empresa: "Demo Este", etapa: "ganada", importe: 240000, probabilidad: 1 },
];

const resumen = oportunidades.reduce(
  (resultado, oportunidad) => {
    const { etapa, importe, probabilidad } = oportunidad;

    resultado.porEtapa[etapa] =
      (resultado.porEtapa[etapa] ?? 0) + importe;

    if (etapa !== "ganada" && etapa !== "perdida") {
      resultado.pipelinePonderado += Math.round(importe * probabilidad);
    }

    return resultado;
  },
  { porEtapa: {}, pipelinePonderado: 0 }
);

const euros = (centimos) =>
  new Intl.NumberFormat("es-ES", {
    style: "currency",
    currency: "EUR",
  }).format(centimos / 100);

console.table(
  Object.entries(resumen.porEtapa).map(([etapa, importe]) => ({
    etapa,
    importe: euros(importe),
  }))
);

console.log("Pipeline ponderado:", euros(resumen.pipelinePonderado));
// Pipeline ponderado: 2.280,00 €
```

**Posible evolución:** interfaz React, filtros, historial de actividad y persistencia.

</details>

<details>
<summary><strong>▦ Stock ERP — propuesta de reposición de inventario</strong></summary>

Detecta productos cuyo stock disponible está por debajo del mínimo.
Tiene en cuenta reservas y pedidos pendientes de recibir.

```js
const inventario = [
  { sku: "DEMO-001", stock: 8, reservado: 3, enCamino: 2, minimo: 10, objetivo: 25 },
  { sku: "DEMO-002", stock: 40, reservado: 5, enCamino: 0, minimo: 15, objetivo: 50 },
  { sku: "DEMO-003", stock: 4, reservado: 1, enCamino: 15, minimo: 8, objetivo: 20 },
];

const reposicion = inventario
  .map((producto) => {
    const disponible = producto.stock - producto.reservado;

    const pedir =
      disponible < producto.minimo
        ? Math.max(
            0,
            producto.objetivo - disponible - producto.enCamino
          )
        : 0;

    return { sku: producto.sku, disponible, pedir };
  })
  .filter((producto) => producto.pedir > 0);

console.table(reposicion);
// DEMO-001 → disponible: 5 → pedir: 18
// DEMO-003 → disponible: 3 → pedir: 2
```

**Posible evolución:** panel de inventario, movimientos de almacén y avisos de reposición.

</details>
